# Nut Classification CNN

## Описание проекта
Этот проект представляет собой сверточную нейронную сеть (CNN), разработанную для классификации орехов на "хорошие" и "плохие". Нейросеть обучается на изображениях орехов, после чего может предсказывать качество новых изображений.

Модель обучалась на изображениях орехов и может предсказывать качество новых фотографий.

Проект сделан в рамках учебного проекта Data Science, демонстрирует:
- работу с изображениями в TensorFlow/Keras,
- подготовку данных и split train/val/test,
- подбор гиперпараметров (количество эпох, оптимизаторы),
- финальное обучение модели и сохранение весов.

Точность модели на тестовых данных (500 изображений) составила 94.8%.

## Используемые технологии
- TensorFlow + Keras
- NumPy
- PIL (работа с изображениями)

## Подготовка данных
В ходе работы было отснято **5000 фотографий орехов** на **зеленом фоне** в двух классах:
- **2500 фотографий хороших орехов**
- **2500 фотографий плохих орехов**

## Обучение модели
- Данные автоматически разделяются на train/val/test через train_test_split.
- Препроцессор ресайзит изображения до (150,150), нормализует в [0,1].
- Генераторы SimpleImageDataset создаются для обучения и валидации.

После обучения все веса модели сохранены в `artefacts/final_model.keras` для воспроизводимости.

## Можно использовать модель для предсказаний на ваших фото (без всех исходных данных, но основе обученных весов)

* Веса модели лежат в `artefacts/final_model.keras` (уже обученные).
* Эти веса можно использовать без исходных фотографий для тестирования предсказаний.
* Перед использованием весов, нужно создать `preprocessor` для каждого "входящего" фото
* Пример реализованного `preprocessor` в notebooks/Nut_classify_CNN_v5-27.04.ipynb
